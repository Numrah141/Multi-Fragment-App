# Multi-Fragment-App
# Project Overview
A simple Android application that demonstrates the use of Fragments and SharedPreferences for persistent data storage. The app allows users to save their personal information and view it across different fragments.
# Features
Two Fragments: Settings and Profile display

Data Persistence: Uses SharedPreferences to save user data

Data Validation: Ensures all fields are properly filled

User-Friendly Navigation: Easy switching between fragments

Reset Functionality: Clear all stored data with one click
